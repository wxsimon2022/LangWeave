# LangWeave Backend

FastAPI application layer (`app/`) plus the LangChain/LangGraph agent framework
(`langweave/`).

## Run

```bash
cd backend-chat
pip install -r requirements.txt
cp .env.example .env            # then fill in the required values
uvicorn main:app --reload --port 30002
```

## Layout

| Path | Purpose |
|------|---------|
| `langweave/` | Core agent framework (LangChain + LangGraph) |
| `app/` | FastAPI application wiring, domain, infrastructure, routes |
| `config/` | MCP and prompt configuration (YAML) |
| `sql/` | Schema and migration scripts |
| `scripts/` | Utilities such as `init_agents.py` |
| `docs/` | Project docs and files generated by the file assistant |
| `examples/` | Runnable examples |

See the repository root [README.md](../README.md) for the full project overview.
