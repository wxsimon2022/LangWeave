# LangWeave 开发指南

框架 API 见 [framework-reference.md](framework-reference.md)；项目总览见 [README.md](../../README.md)。

---

## 1. 环境准备

| 组件 | 版本 | 用途 |
|------|------|------|
| Python | ≥ 3.11 | 后端 |
| Node.js | ≥ 18 | 前端构建 |
| MySQL | 8.x | 数据库 |
| Redis | 7.x | 心跳、单设备登录、DAU |

```bash
cp backend-chat/.env.example backend-chat/.env
(cd backend-chat && pip install -r requirements.txt)
(cd frontend-chat/fe && npm install)
(cd frontend-chat/admin && npm install)   # 管理后台
```

`backend-chat/.env` 示例：

```env
DEEPSEEK_API_KEY=sk-your-key
LANGWEAVE_MODEL=deepseek:deepseek-chat
LANGWEAVE_JWT_SECRET=dev-secret-change-me
LANGWEAVE_DATABASE_URL=mysql+pymysql://root:password@127.0.0.1:3306/langweave
LANGWEAVE_REDIS_URL=redis://127.0.0.1:6379/0
```

## 2. 本地开发

**后端**

```bash
cd backend-chat
uvicorn main:app --reload --port 8000
```

入口 `main.py` → `app.core.app.create_app()` · Swagger `http://127.0.0.1:8000/docs`

**前端**

```bash
cd frontend-chat/fe && npm run dev
```

- 开发地址：`http://127.0.0.1:5173`
- 聊天 SPA：`app.html`
- 宣传页：`public/index.html`
- Vite 代理 `/api` → `:8000`

**联调**

| 项 | 说明 |
|----|------|
| API 基址 | `VITE_API_BASE_URL` 留空走同源 |
| Token | `localStorage.langweave_token` |
| 登录态 | `App.vue` 用 `authCheckDone` + `restoreSession()` 恢复 `/api/v1/auth/me` |

**管理后台**：`cd frontend-chat/admin && npm run dev`（`:5174`）

## 3. 代码导航

```
frontend-chat/fe/src/api/client.js  →  POST /api/v1/unified/stream
backend-chat/app/api/v1/agents_unified.py
backend-chat/app/api/v1/conversations.py
backend-chat/app/application/services/chat.py
backend-chat/app/application/services/intent.py
backend-chat/app/agents/intent_agent.py
backend-chat/app/agents/research_agent_v2.py      # emotional
backend-chat/app/agents/general_agent_v2.py       # assistant
backend-chat/app/interfaces/http/router.py
backend-chat/app/interfaces/http/auth_routes.py
```

**HTTP 路由**（`backend-chat/app/interfaces/http/router.py`）：unified · conversations · auth · heartbeat · admin · session

**鉴权**：JWT + Redis session（`set_active_session_sync`）

## 4. 开发任务

**新增 Agent**

1. `backend-chat/app/agents/` 实现并在 registry 注册
2. `IntentService` / `agent_mapping` 配置 intent → agent
3. 业务 HTTP 扩展 `backend-chat/app/api/v1/` 或 `backend-chat/app/interfaces/http/`

**前端**

```bash
cd frontend-chat/fe && npm run dev && npm run build
```

**测试**：`cd backend-chat && pytest tests/ -q`

## 5. 部署

**Bash（生产）**

```bash
bash backend-chat/script/deploy/deploy.sh
bash backend-chat/script/deploy/build_desktop.sh
```

配置见 [backend-chat/script/deploy/README.md](../../backend-chat/script/deploy/README.md)

**Docker**

```bash
cp backend-chat/.env.example backend-chat/.env
docker compose --env-file backend-chat/.env up -d --build
```

- 服务：`app` + `nginx`
- 访问：`http://localhost:8088`
- MySQL / Redis：远端，通过 `backend-chat/.env` 连接

详见 [docker-reference.md](docker-reference.md)
