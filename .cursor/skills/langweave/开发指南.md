## 1. 环境准备

### 依赖

| 组件 | 版本要求 | 用途 |
|------|----------|------|
| Python | ≥ 3.11 | 后端 |
| Node.js | ≥ 18（推荐 20） | 前端构建 |
| MySQL | 8.x | 生产/联调（可选 SQLite 本地） |
| Redis | 7.x | 心跳、单设备登录、DAU |

### 初始化

```bash
pip install -r requirements.txt
cp .env.example .env
cd frontends/fe && npm install
cd frontends/admin && npm install   # 可选
```

`.env` 最小配置：

```env
DEEPSEEK_API_KEY=sk-your-key
LANGWEAVE_MODEL=deepseek:deepseek-chat
LANGWEAVE_JWT_SECRET=dev-secret-change-me
LANGWEAVE_DATABASE_URL=mysql+pymysql://root:password@127.0.0.1:3306/langweave
LANGWEAVE_REDIS_URL=redis://127.0.0.1:6379/0
```

## 2. 本地开发

### 后端

```bash
uvicorn main:app --reload --port 8000
```

- 入口：`main.py` → `app.core.app.create_app()`
- Swagger：`http://127.0.0.1:8000/docs`

### 前端

```bash
cd frontends/fe && npm run dev
```

- 地址：`http://127.0.0.1:5173`
- **SPA 入口**：`app.html`（非 `public/index.html`）
- Vite 代理 `/api` → `:8000`

### 联调

| 项 | 说明 |
|----|------|
| API 基址 | `VITE_API_BASE_URL` 留空即同源 |
| Token | `localStorage.langweave_token` |
| 刷新闪登录页 | 保持 `authCheckDone` 三态 UI，勿只用 `v-if="!authenticated"` |

## 3. 架构与代码导航

```
frontends/fe/src/api/client.js → POST /api/v1/unified/stream
app/api/v1/agents_unified.py
app/application/services/chat.py
app/application/services/intent.py
app/agents/intent_agent.py | research_agent_v2.py | general_agent_v2.py
app/interfaces/http/router.py
```

**已移除旧 API**：`/api/v1/emotional-chat/*`、`/chat/*`、业务 `/intent/*`

**鉴权**：`auth_routes.py` · Redis session 用 `set_active_session_sync`

---

## 4. 常见开发任务

- **新增 Agent**：`app/agents/` → registry → `IntentService` 映射 → 避免与 `/{name}/stream` 路径冲突
- **改前端**：`npm run dev` / `npm run build` → Docker 或 deploy 需重建
- **测试**：`pytest tests/ -q`（无需 API Key）

## 5. 部署

详见 [script/deploy/README.md](../../script/deploy/README.md)

### Docker

```bash

docker compose up -d --build
```

访问 `http://localhost:8088`。MySQL/Redis 用远端，compose 仅 `app` + `nginx`。

详见 [docker-reference.md](docker-reference.md)

## 6. 常见问题

| 现象 | 处理 |
|------|------|
| `Unknown agent: unified` | unified router prefix 改为 `/api/v1` |
| `cannot reuse already awaited coroutine` | 用 `set_active_session_sync` |
| 刷新闪登录页 | 保持 `authCheckDone` |
| Docker `/` 404 | nginx 用 `root`+`try_files`，勿全 proxy 到 app |
| SSE 无流式 | `proxy_buffering off` |
